# 後期課題：「ずっと続くもの」をテーマにした小説

## 課題内容
- テーマ：「ずっと続くもの」をテーマとした作品を作る（個人制作）
- 媒体：小説
- 発表：10〜15分のプレゼン（+デモンストレーション）・展示
- 発表で説明すること：なぜそれを選んだか、続くことをどのように捉えたか

## フォルダ構成

| フォルダ | 中身 | 主なファイル |
|---|---|---|
| `00_企画` | テーマの捉え方、作品の方向性 | `企画書.md` |
| `01_プロット` | 全体の構成、章ごとの流れ | `プロット.md` |
| `02_設定` | 登場人物、舞台、「続くもの」の設定 | `登場人物.md`、`世界観と舞台.md`、`続くものの設定.md` |
| `03_本文` | 小説の本文（章ごと） | `第01章.md` 〜 |
| `04_資料メモ` | 調べたこと、アイデア、改稿メモ | `アイデア帳.md`、`資料メモ.md`、`改稿メモ.md` |
| `05_発表` | プレゼン原稿、スライド構成、展示用の文 | `発表原稿.md` |

## 進め方（おすすめの順番）
1. `00_企画/企画書.md` で「続くもの」を何にするか、なぜそれを選ぶかを決める
2. `02_設定` で登場人物と舞台を作る
3. `01_プロット/プロット.md` で章立てを決める
4. `03_本文` に章ごとに書く
5. `04_資料メモ/改稿メモ.md` に直すべき点を残しながら推敲する
6. `05_発表/発表原稿.md` を作る（作品の説明と「続くことの捉え方」が中心）
