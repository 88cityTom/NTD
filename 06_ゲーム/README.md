# 06_ゲーム：コミュ（ADVパート）UI のたたき台

時間をテーマにしたゲームの、会話シーン（コミュ）だけの画面。ゲームの仕組み（能力・数値・分岐条件）はまだ入っていない。
新作ゲーム『アステリズムの手記』の `js/commu.js` と同じ作りで組み、時間のテーマに合わせて見た目と演出を変えている。

## 開き方
- `index.html` をブラウザで開く（ダブルクリックでも動く）
- ローカルサーバーで開く場合は、NTD のルートで次を実行して http://localhost:5180 を開く

```bash
python -m http.server 5180 --directory 06_ゲーム
```

## 操作
| 操作 | 内容 |
|---|---|
| クリック／Enter／Space | 次へ（文字送り中なら全文を出す） |
| H／右クリック | ウィンドウを隠す |
| L／ホイール上 | 会話の記録 |
| A | オート |
| Ctrl 長押し | 早送り（選択肢で止まる） |
| Esc | 開いているものを閉じる |

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` | 画面の骨組み |
| `css/commu.css` | 見た目。冒頭の DESIGN TOKENS（色・書体・角丸）を差し替えれば全体のトンマナが変わる |
| `js/commu.js` | 再生エンジン |
| `js/data/characters.js` | 登場人物（名前・色・時間観の札）。すべて仮 |
| `js/data/episodes.js` | 台本。いまは UI 確認用のダミーだけ。書ける項目は冒頭のコメントにある |

## 画像の置き場所（webp）
- 立ち絵：`assets/chara/<人物id>_<表情>.webp`　例：`a_normal.webp`、`a_smile.webp`
  - 表情の画像がなければ `<人物id>_normal.webp` を使い、それもなければ仮の影とファイル名を出す
  - 立ち絵は、足もと（画像の下端）を画面の下端にそろえて表示する。背景を抜いた縦長の画像を想定
- 背景：`assets/bg/<背景id>.webp`　例：`sample_01.webp`
  - 画像がないあいだは、背景 id ごとに色味の違う夜の地を出す

## 仮のまま決めたこと（あとで話して決める）
- 色・書体・装飾（夜の地に冷たい光の線。人物ごとの色だけが温度を持つ）
- 人物は「他者A（座標の時間）」「他者B（伸縮する時間）」の仮名。発表原稿の二つの例から札だけ借りている
- 時刻表示の書式（`T+00:00:12` など）は、台本に書いた文字列をそのまま出しているだけ
- 時間の演出は「巻き戻し」「停止」「伸縮」の三つを試しに用意した
- デスクトップ表示のみ（参考にした新作ゲームと同じ）

## まだ入っていないもの
- 選択肢の効果（数値の変化・フラグ）と、条件による鍵の判定（`locked` は表示だけ）
- セーブ／ロード、既読スキップ、音
- タイトル画面などコミュ以外の画面
